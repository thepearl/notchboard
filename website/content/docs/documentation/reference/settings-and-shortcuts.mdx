## Settings

Open with ⌘, from the panel, or from the menu-bar item.

### Behaviour

| Setting                                       | What it does                                                                                          | Default    |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ---------- |
| Start expanded when docking                   | Whether Notchboard comes up as the full panel or the notch at launch                                  | On         |
| Dock to                                       | Which edge of the Simulator window the notch attaches to. The notch and the coach mark mirror with it | Right edge |
| Auto-release in-use elements after N min idle | How long your own in-use mark survives before releasing itself. 5 to 240, in steps of 5               | 60 min     |
| Global shortcut                               | The modifier both global chords use                                                                   | ⌃ Control  |
| Play a sound with notifications               | Whether a notify-when-free notification makes a sound                                                 | On         |
| Launch at login                               | Starts Notchboard when you log in                                                                     | Off        |

If macOS puts the login-item registration in a pending state, a "Pending your approval in Login Items" row appears with a button that opens the right System Settings pane.

### Debug deeplink

Scoped to the active collection.

| Setting                                                | What it does                                                       | Default |
| ------------------------------------------------------ | ------------------------------------------------------------------ | ------- |
| Debug URL scheme                                       | The scheme one-click login fires into. One per collection          | None    |
| Warn before mixing production with another environment | Asks once, at save, when an element mixes `PRD` with anything else | On      |

### Team room

Also scoped to the active collection. With a room joined it shows the room name and broker host, the connection status with the online count, and a Leave Room button. Without one it reads "Local — no team room." and offers a Join with an Invite button.

At the bottom of the window, **Replay Onboarding** restarts the first-run flow. It asks for confirmation first, because finishing onboarding replaces the active collection.

## Keyboard

| Chord  | What it does                                                    |
| ------ | --------------------------------------------------------------- |
| ⌃K     | Expand the panel, show the list, focus the search field. Global |
| ⌃N     | Expand the panel, open the add-element form. Global             |
| ↑ ↓    | Move through the list, scrolling the highlighted row into view  |
| Return | Open the highlighted element                                    |
| Esc    | Go back to the list from a detail, add or group screen          |
| ⌘,     | Open Settings. Works during onboarding too                      |

The two global chords share one modifier, settable to ⌃, ⌘ or ⌥⌘ in Settings. The change takes effect immediately. Inside the panel, plain ⌘K and ⌘N always work whatever the global modifier is.

<Callout type="info">
**Global here is scoped, deliberately.** The chords are registered only while Xcode, Simulator or Notchboard is frontmost, and only while the panel is in a state to respond. Everywhere else they go straight back to the system.

That is what makes ⌃K an acceptable default at all, since it is `kill-line` in your shell and delete-to-end-of-paragraph in every Cocoa text view. Switch to Terminal and it goes back to being those things on the next tick.
</Callout>

## Menu bar

| Item                     | What it does                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Toggle Expand / Collapse | Flips between the notch and the full panel                                                                     |
| Show Panel (Undocked)    | Shows the panel free-floating and draggable, and outranks docking. The item then reads Dock Again |
| Join Room with Invite    | Paste an invite line and a room password to join a teammate's room                                             |
| Export Collection        | Writes the active collection to a password-protected `.notchboard` file                                        |
| Import Collections       | Adds one or more files as new collections, destroying nothing                                                  |
| Restore Snapshot         | Replaces all collections from an encrypted local snapshot                                                      |
| Settings                 | Opens the settings window                                                                                      |
| Quit Notchboard          | Quits, releasing the global chords and flushing state to disk                                                  |

## The collection menu

The ▾ next to the collection name in the panel header.

| Item                | What it does                                                              |
| ------------------- | ------------------------------------------------------------------------- |
| \<collection name>  | One row per collection, with a checkmark on the active one                |
| new collection      | Creates an empty catalogue with one seeded group and switches to it       |
| rename              | Renames the catalogue. With a room joined, the new name travels           |
| duplicate           | Copies it, minting fresh element ids so secrets do not alias              |
| set deeplink scheme | The URL scheme one-click login fires into                                 |
| set up team room    | Broker URL, room name, room password                                      |
| copy room invite    | Puts the one-line invite on the pasteboard. Shown only once a room exists |
| join with an invite | Shown only when the collection has no room                                |
| leave room          | Keeps everything local and stops sending and receiving                    |
| delete              | Removes the collection and its secrets. Disabled when it is the last one  |

## The element list

| Control            | What it does                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------- |
| search             | Case-insensitive match over name, note and every non-secret field value in the active group |
| environment filter | Four chips, `ALL` `DEV` `STG` `PRD`, single-select                                          |
| favourite          | A star per row. Local only, it never travels to a room                                      |
| group tabs         | One tab per group with its count, plus editing and adding                                   |

## Uninstalling

In this order, because the first step needs the app to still be there.

<Steps>
<Step>
#### Turn off launch at login

Open Settings from the menu bar and switch it off. The app unregisters its own login item. Skipping this leaves the login item behind. If the app is already gone, remove it by hand in System Settings, General, Login Items.
</Step>

<Step>
#### Quit and delete the app

```bash
rm -rf /Applications/notchboard.app
```
</Step>

<Step>
#### Delete its data

```bash
rm -rf ~/Library/Application\ Support/Notchboard
rm -rf ~/.notchboard
```
</Step>

<Step>
#### Remove the Keychain items

Each call removes one matching item, so repeat each line until it reports nothing left to find.

```bash
security delete-generic-password -s flourix.notchboard.secrets
security delete-generic-password -s flourix.notchboard.rooms
security delete-generic-password -s flourix.notchboard.device
```
</Step>

<Step>
#### Remove the stale permission rows

System Settings, Privacy & Security, Accessibility, select Notchboard and click minus. Do the same under Notifications if you ever allowed notify-when-free alerts.
</Step>
</Steps>

A few files that AppKit writes for any bundle identifier may also exist, and are safe to delete.

```bash
rm -rf ~/Library/Caches/flourix.notchboard
rm -f  ~/Library/Preferences/flourix.notchboard.plist
rm -rf ~/Library/Saved\ Application\ State/flourix.notchboard.savedState
```

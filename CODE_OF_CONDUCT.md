# Code of conduct

This is a small project. The rules are short.

Be decent to people. Assume the person on the other end is trying to help, including when they are
wrong. Criticise the code, the design or the argument, never the person making it.

Not welcome here: harassment, personal attacks, discriminatory or sexual language, posting someone's
private information, and sustained disruption of a discussion.

If something crosses that line, report it to the maintainer at ghazi.tozri98@gmail.com. Reports stay
between you and the maintainer. Responses run from asking someone to stop, through editing or
removing the content, to blocking an account, and the maintainer decides which one fits.

This applies to issues, pull requests, commit messages and anywhere else the project is being
discussed.
